### Reminders

Subject details we should make sure to not forget about.

1. All roles must be clearly documented in README.md \
(Product Owner, Project Manager, Tech lead, Dev)
2. All team members should be able to explain the project and their contributions.
3. The website must be compatible with latest stable version of Google Chrome.
4. No warnings or errors should appear in the browser console.
5. The project must include accessible Privacy Policy and Terms of Service pages with the relevant content.\
These pages will be verified during evaluation.\
They must:
- Be easily accessible from the app.
- Contain relevant and appropriate content for your project.
- Not be placeholder or empty pages.
6. Multi-user Support: the website must support multiple users simultaneously. This is a core requirement of the project.
- Multiple users can be logged in and active at the same time.
- Concurrent actions by different users are handled properly.
- Real-time updates are reflected across all connected users when
applicable.
- No data corruption or race conditions occur with simultaneous
user actions.
7. Be sure to manage the credentials correctly.
